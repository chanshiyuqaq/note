### 逆否命题  
  对于给定条件命题 $P \Rightarrow Q$（如果 $P$，则 $Q$），它的逆否命题是 $\neg Q \Rightarrow \neg P$（如果不是 $Q$，则不是 $P$）。

- **逻辑等价性**：原命题与它的逆否命题具有相同的真值，即 $P \Rightarrow Q \equiv \neg Q \Rightarrow \neg P$。  
- **常见误区区分**：
  - **逆命题 (Converse)**：$Q \Rightarrow P$（与原命题不等价）
  - **否命题 (Inverse)**：$\neg P \Rightarrow \neg Q$（与原命题不等价，实际上是逆否命题的逆命题）
  - **逆否命题**：唯一与原命题逻辑等价的变体

- **应用示例**：  
  原命题：“如果今天下雨，那么地面湿。”（$P$：下雨，$Q$：地湿）  
  逆否命题：“如果地面不湿，那么今天没下雨。”  
  此推理有效，因为若地干则不可能下雨（否则地应湿），等价于原条件。

制造函数差值，进而证明不等关系：
例：
#### 例① 对数不等式：$\boldsymbol{\ln\left(1+\frac{1}{x}\right) > \frac{1}{x+1} \quad (x>0)}$

1. 对数拆分为差值： $$\ln\left(1+\frac{1}{x}\right) = \ln\frac{x+1}{x} = \ln(x+1)-\ln x$$
2. 转化为积分形式（$(\ln t)'=\frac{1}{t}$）： $$\ln(x+1)-\ln x = \int_x^{x+1} \frac{1}{t} \mathrm{d}t$$
3. 积分放缩：在区间 $x < t < x+1$ 上，$\frac{1}{t}$ 单调递减，故 $\frac{1}{t} > \frac{1}{x+1}$，因此 $$\int_x^{x+1} \frac{1}{t} \mathrm{d}t > \int_x^{x+1} \frac{1}{x+1} \mathrm{d}t = \frac{1}{x+1}$$
4. 结论： $$\ln\left(1+\frac{1}{x}\right) > \frac{1}{x+1} \quad (x>0)$$
#### 例② 函数有界性放缩

已知：$f'(x)=\frac{1}{x^2+1}$，$x\geqslant1$，且 $(f(1)=1)$，求证 $\boldsymbol{f(x) < 1+\frac{\pi}{4}}$。

1. 函数表示为初值+积分增量： $$f(x) = f(1) + \int_1^x f'(t)\mathrm{d}t = 1 + \int_1^x \frac{1}{1+t^2}\mathrm{d}t$$
2. 积分放缩：被积函数恒正，扩大积分上限至无穷，积分值变大： $$\int_1^x \frac{1}{1+t^2}\mathrm{d}t < \int_1^{+\infty} \frac{1}{1+t^2}\mathrm{d}t$$
3. 计算反常积分： $$\int_1^{+\infty} \frac{1}{1+t^2}\mathrm{d}t = \left.\arctan t\right|_1^{+\infty} = \frac{\pi}{2} - \frac{\pi}{4} = \frac{\pi}{4}$$
4. 结论： $$f(x) < 1+\frac{\pi}{4}$$

---

#### 例③ 调和级数上界：$\boldsymbol{\ln(1+n) < 1+\frac{1}{2}+\cdots+\frac{1}{n}}$

1. 对数拆分为分段积分之和： $$\ln(1+n) = \int_1^{n+1} \frac{1}{x}\mathrm{d}x = \sum_{k=1}^n \int_k^{k+1} \frac{1}{x}\mathrm{d}x$$
2. 逐项积分放缩：在区间 $[k,,k+1]$ 上，$\frac{1}{x}$ 单调递减，故 $\frac{1}{x} < \frac{1}{k}$，因此 $$\int_k^{k+1} \frac{1}{x}\mathrm{d}x < \int_k^{k+1} \frac{1}{k}\mathrm{d}x = \frac{1}{k}$$
3. 求和得结论： $$\ln(1+n) < \sum_{k=1}^n \frac{1}{k} = 1+\frac{1}{2}+\cdots+\frac{1}{n}$$

---

#### 例④ 调和级数下界：$\boldsymbol{\ln n > \frac{1}{2}+\frac{1}{3}+\cdots+\frac{1}{n}}$

1. 对数拆分为分段积分之和： $$\ln n = \int_1^n \frac{1}{x}\mathrm{d}x = \sum_{k=2}^n \int_{k-1}^k \frac{1}{x}\mathrm{d}x$$
2. 逐项积分放缩：在区间 $[k-1,,k]$ 上，$\frac{1}{x}$ 单调递减，故 $\frac{1}{x} > \frac{1}{k}$，因此 $$\int_{k-1}^k \frac{1}{x}\mathrm{d}x > \int_{k-1}^k \frac{1}{k}\mathrm{d}x = \frac{1}{k}$$
3. 求和得结论： $$\ln n > \sum_{k=2}^n \frac{1}{k} = \frac{1}{2}+\frac{1}{3}+\cdots+\frac{1}{n}$$
