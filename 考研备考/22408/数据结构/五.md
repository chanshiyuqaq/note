树的基本概念
树的性质：
- 树的节点数等于树的总度数+1，因为在树中一条边对应一个度，所以树中节点数等于边数+1
- 度为m的树中，第i层至多有$m^{i-1}$个节点
- 高度为h的m叉树最多节点数，使用等比数列求和公式求解，1,m,$m^2$.....
- 反过来计算具有n个节点的树的最小高度
- 度为m,n个节点的树的最大高度为n-m+1
计算题中重要的恒等式：总节点=分支节点+叶节点，总节点=总度数+1
区分二叉树与度为2的树，二叉树可以为空；度为2的有序树在只有一个孩子的情况下，不区分左右；而二叉树要区分左右

区分完全二叉树与满二叉树
==正则二叉树是指==，树中仅有度为0或者为2的节点

二叉树的性质：
- 度为0的节点=度为2的节点+1
	推导过程: N=n0+n1+n2=(度数+1)=(n1+2n2+1)
- 在稠密情况下，等比数列，可以得到第k层最多有多少节点
- 高为h的二叉树最多有多少个节点

完全二叉树的性质
- 对于编号为从1到n的完全二叉树，最后一个==分支节点==的编号为n/2下取整
- 叶节点只可能出现在最后两层
- 只有最后一个分支节点的度可能为1，且该节点有左孩子没有右孩子
- n为奇数，每个分支节点都有左右孩子，n为偶数，分支节点只有左孩子，没有右孩子
- 结点i所在层次(深度为 logi 下取整+1
- n个节点，完全二叉树的高度为 ==log(n+1)后==上取整，或者 ==logn下取整==后+1

二叉树的存储结构
- 顺序存储结构指的是，将二叉树从上到下，从左到右，顺序存储到数组中，适合完全、满二叉树，不是完全，满二叉树的结构的需要补充空节点
- 链式存储，每个节点包含若干数据域和指针域，lchild data rchild
- n个节点的二叉链表中有n-1个边，n个节点有能力存储2n条边，但是只有n-1个边，剩余n+1个空白的指针域

bool identical(BiTree*T1,BiTree*T2)
{

	if(T1==Null && T2==Null)
	return 1;
	if(T1==Null || T2==Null)
	return 0;

	return (T1->data == T2->data)
          && identical(T1->left, T2->left)
          && identical(T1->right, T2->right);
    
}


求值为x的节点的双亲

  // 在树 T 中找到值为 x 的结点的双亲，parent 是当前节点 T 的双亲
  BiTree* FindParent(BiTree *T, BiTree *parent, ElemType x)
  {
      if (T == NULL)
          return NULL;
      // 当前节点的左孩子或右孩子是目标 → 当前节点就是双亲
      if ((T->left  != NULL && T->left->data  == x) ||
          (T->right != NULL && T->right->data == x))
          return T;
      // 去左子树找
      BiTree *p = FindParent(T->left, T, x);
      if (p != NULL)
          return p;
      // 去右子树找
      return FindParent(T->right, T, x);
  }



求值为x的节点

  BiTree* FindNode(BiTree *T, ElemType x)
  {
      if (T == NULL)
          return NULL;
      if (T->data == x)
          return T;

      BiTree *res = FindNode(T->left, x);
      return res ? res : FindNode(T->right, x);
  }

由遍历序列构造二叉树：
知道中序序列和其余序列的任意一种，即可构造出完整的二叉树

手算方法：由层序 + 中序画二叉树

  ---
  核心口诀

  层序定根，中序分左右。从层首到层尾逐个"落位"。

  ---
  示例

  层序: A  B  C  D  E  F  G  H
  中序: D  B  G  E  A  F  H  C

  ---
  步骤一：层序第一个是整棵树的根

  层序: [A]  B  C  D  E  F  G  H     ← A 是根
  中序:  D  B  G  E [A] F  H  C      ← A 分割中序
                 ↑
           左: D B G E    右: F H C

          A
         / \
    左子树  右子树

  ---
  步骤二：继续，层序第二个 B

  B 只能在 已存在的结点的空位上。根 A 的左右都空着，B 是谁的孩子？

  关键：看 B 在中序中和 A 的相对位置。

  中序: D [B] G  E  A  F  H  C
           ↑
       B 在 A 左边 → B 是 A 的左孩子

          A
         /
        B

  ---
  步骤三：层序第三个 C

  中序: D  B  G  E  A  F  H [C]
                             ↑
                    C 在 A 右边 → C 是 A 的右孩子

          A
         / \
        B   C

  ---
  步骤四：层序第四个 D

  D 在谁下面？看中序中 D 和已落位的 A、B、C 的关系：

  中序: [D] B  G  E  A  F  H  C
         ↑
  D 在 B 左边，在 A 左边 → 沿"左下"方向找能插的空位

  通用规则：对于待插入的结点 X，在中序中找到 X 的位置，看它最近的那个已落位祖先：

  中序: D ... B ... A ...
        ↑         ↑    ↑
        D在B左  B是A左

  D 的中序位置在 B 左边 → D 挂到最近的可能空位

  因为 B 的左右孩子都空着，D 又在 B 左边，所以 D 是 B 的左孩子。

          A
         / \
        B   C
       /
      D

  ---
  步骤五：层序第五个 E

  中序: D  B  G [E] A  F  H  C
             ↑     ↑
        E在B右，B是A左

  B 的右孩子空着 → E 是 B 的右孩子

          A
         / \
        B   C
       / \
      D   E

  ---
  步骤六：层序第六个 F

  中序: ... A [F] H  C
              ↑
        F在A右，F在C左

  看已落位：A 的左有 B，右有 C。F 在 A 右且在 C 左。
  C 的左孩子空着 → F 是 C 的左孩子

          A
         / \
        B   C
       / \  /
      D   E F

  ---
  步骤七：层序第七个 G

  中序: D  B [G] E  A  F  H  C
              ↑
       G在B右，G在E左

  B 的右已被 E 占据。G 在 E 的左边 → G 是 E 的左孩子

  ---
  步骤八：层序第八个 H

  中序: ... A  F [H] C
                  ↑
       H在F右，H在C左

  F 的左右都空，H 在 F 右边 → H 是 F 的右孩子

  ---
  最终结果

              A
            /   \
           B     C
          / \   /
         D   E F
            /   \
           G     H

  ---
  手算步骤总结

  ①  层序第一个 = 整棵树根 → 在中序中标记，切分左右
  ②  层序第二个开始，逐个处理：
      a) 在中序中定位该结点
      b) 找它"最近的已落位祖先"
      c) 根据在中序中的左右关系，挂到对应空位上
  ③  重复②直到所有结点落位
