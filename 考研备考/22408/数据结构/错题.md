### 绪论部分
关于数据结构的说法中正确的是：**数据的逻辑结构独立于数据的存储结构**
同一个逻辑结构--->不同的底层实现

### 时间复杂度部分
```cpp
int sum = 0;
for(int i = 1; i < n;i*=2)
{
	for(int j = 0;j < i ;j++)
	{
		//something
	}
}
```
上面算法的时间复杂度为O(n)
举例子:当n = 16的时候
注意这里是小于号，不是小于等于号！
执行如下：
1->.
2->..
4->....
8->........
到此为止，相当于进行了15次操作，时间复杂度为O(n)

### 分析斐波那契数列的时间复杂度：

$$F(n) = \begin{cases} 0 & n = 0 \\ 1 & n = 1 \\ F(n-1) + F(n-2) & n > 1 \end{cases}$$
使用递归方式求解F(5) ，对应的二叉树的高度为5 ， 节点数为
$$
2^5-1
$$
时间复杂度是$$O(2^n)$$
### 空间复杂度的计算的时候
函数递归调用栈分两种情况：
- 空间开销与递归深度无关，即每次递归的开销是常量，O(n)
- 空间开销与深度相关，这时候需要进行计算

### 递归实现总结（二叉树）

统一结点定义：

```cpp
struct Node {
    int data;                  // 结点值（WPL 中叶子为权值）
    Node *lchild, *rchild;
};
```

#### 1. 求带权路径长度 WPL（哈夫曼树）

- 路径长度 = 根到叶子的边数，**根深度从 0 开始**
- 全局变量法：

```cpp
long long sum = 0;
void dfs(Node* root, int depth) {
    if (!root) return;
    if (!root->lchild && !root->rchild) { sum += root->data * depth; return; }
    dfs(root->lchild, depth + 1);
    dfs(root->rchild, depth + 1);
}
```

- 返回值法（无全局变量，推荐）：

```cpp
long long wpl(Node* root, int depth) {
    if (!root) return 0;
    if (!root->lchild && !root->rchild) return root->data * depth;
    return wpl(root->lchild, depth + 1) + wpl(root->rchild, depth + 1);
}
```

#### 2. 判断二叉搜索树 BST

- **关键**：BST 是全局约束（左子树全 < 根 < 右子树全），只比父子不够
- 方法A：中序遍历严格递增

```cpp
int prev = INT_MIN;
bool ok = true;
void inorder(Node* root) {
    if (!root || !ok) return;
    inorder(root->lchild);
    if (root->data <= prev) { ok = false; return; }
    prev = root->data;
    inorder(root->rchild);
}
```

- 方法B：传合法区间 (low, high)

```cpp
bool check(Node* root, long long low, long long high) {
    if (!root) return true;
    if (root->data <= low || root->data >= high) return false;
    return check(root->lchild, low, root->data)
        && check(root->rchild, root->data, high);
}
// 调用 check(root, INT_MIN, INT_MAX)
```

#### 3. 统计度为 0/1/2 的结点个数

- 验证：$n_0 = n_2 + 1$
- 判断度互斥三分支：

```cpp
void countDegree(Node* root, int &n0, int &n1, int &n2) {
    if (!root) return;
    countDegree(root->lchild, n0, n1, n2);
    countDegree(root->rchild, n0, n1, n2);
    if (!root->lchild && !root->rchild) n0++;
    else if (root->lchild && root->rchild) n2++;
    else n1++;
}
```

#### 4. 二叉树宽度（某层最多结点数）

- **关键**：必须按层统计，不能"左 + 右"
- 方法A：DFS + 层计数数组

```cpp
int levelCnt[1000] = {0};
int maxLevel = 0;
void dfs(Node* root, int level) {
    if (!root) return;
    levelCnt[level]++;
    maxLevel = max(maxLevel, level);
    dfs(root->lchild, level + 1);
    dfs(root->rchild, level + 1);
}
int width(Node* root) {
    dfs(root, 1);
    int res = 0;
    for (int i = 1; i <= maxLevel; i++) res = max(res, levelCnt[i]);
    return res;
}
```

- 方法B：层序遍历 BFS

```cpp
int width(Node* root) {
    if (!root) return 0;
    queue<Node*> q; q.push(root);
    int res = 0;
    while (!q.empty()) {
        int cnt = q.size(); res = max(res, cnt);
        for (int i = 0; i < cnt; i++) {
            Node* p = q.front(); q.pop();
            if (p->lchild) q.push(p->lchild);
            if (p->rchild) q.push(p->rchild);
        }
    }
    return res;
}
```

#### 5. 删除所有叶结点

- **关键**：引用参数（或二级指针）置空父节点孩子指针；**先判断叶子再递归**（后序判断会把整棵树删光）

```cpp
void deleteLeaves(Node* &root) {
    if (!root) return;
    if (!root->lchild && !root->rchild) { delete root; root = nullptr; return; }
    deleteLeaves(root->lchild);
    deleteLeaves(root->rchild);
}
```

#### 6. 求某结点所在层次（及时终止）

- **关键**：返回值接住并向上传递；找到立即返回（剪枝）

```cpp
int findLevel(Node* root, Node* p, int height) {
    if (!root) return -1;                        // 没找到
    if (root == p) return height;                // 找到
    int left = findLevel(root->lchild, p, height + 1);
    if (left != -1) return left;                 // 左找到，立即返回
    return findLevel(root->rchild, p, height + 1);
}
// 调用 findLevel(root, p, 1)
```

#### 7. 求所有结点最大值

```cpp
int findMax(Node* root) {
    if (!root) return INT_MIN;
    int l = findMax(root->lchild);
    int r = findMax(root->rchild);
    return max(root->data, max(l, r));
}
```

#### 8. 交换左右孩子（翻转/镜像）

```cpp
void swapChildren(Node* root) {
    if (!root) return;
    swap(root->lchild, root->rchild);
    swapChildren(root->lchild);
    swapChildren(root->rchild);
}
```

#### 9. 尾递归 vs 普通递归

- **关键**：尾递归的递归调用是最后一步、结果直接返回，编译器可优化成循环，空间 O(1)
- 普通递归（返回后还要运算，空间 O(n)）：

```cpp
int fact(int n) { return n <= 1 ? 1 : n * fact(n - 1); }
```

- 尾递归（累加器）：

```cpp
int fact_tail(int n, int acc) { return n <= 1 ? acc : fact_tail(n - 1, n * acc); }
```

#### 10. 求二叉树的直径（任意两结点最长路径）

- **定义**：直径 = 任意两结点间最长路径的**边数**
- **关键**：函数返回的是"树高"，直径需另用全局变量跟踪；经过某结点的最长路径 = 左子树高 + 右子树高

```cpp
int ans = 0;                     // 全局：直径（最长路径边数）

int height(Node* root) {
    if (!root) return 0;          // 空结点高度为 0
    int l = height(root->lchild);
    int r = height(root->rchild);
    ans = max(ans, l + r);        // 经过 root 的最长路径 = 左高 + 右高
    return max(l, r) + 1;         // 返回高度（叶子 = 1）
}

int diameter(Node* root) {
    ans = 0;
    height(root);
    return ans;
}
```
- 若按"结点数"计：把 `ans = max(ans, l + r)` 改成 `ans = max(ans, l + r + 1)`。
