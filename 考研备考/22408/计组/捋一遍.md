在进行除法之前，控制逻辑
- 检查除数是不是0，如果除数是0，调用操作系统的异常处理
- 如果 被除数 ==小于== 除数，商0，余数为被除数

对于除法 2n/n , 结果为n+1位，但是结果只保留n位，此时会发生溢出

通过相加判断正负在决定每一轮是商0还是商1，使用余数寄存器中的值-除数寄存器中的值，大于0商1，小于零商0.注意这里的结果会写入到余数寄存器中！

- 若第一位商等于1，则发生商溢出异常，终止除法运算
	第一为为0，说明不会发生 商溢出 ，不必保存这位商，也不让Cn--,Cn仍为n
对于其他轮：
-  整体左移，右侧空处一位，==因为要用这一位存商==
- 根据减的结果进行上商（如果上商的值是0的话，需要恢复对原寄存器的修改）
- 商1的时候，不用修改

上述的方法叫做恢复余数法结合袁春风教材理解原理

各种跳转逻辑判断：
下面以常见的 **x86 条件转移指令** 为背景，假设刚执行了：

$$
\text{CMP A, B} \quad \text{即计算} \quad A - B
$$

并根据结果设置标志位：

- \(ZF\)：零标志，结果为 0 时置 1；
- \(SF\)：符号标志，结果最高位为 1 时置 1；
- \(OF\)：溢出标志，有符号减法溢出时置 1；
- \(CF\)：进位/借位标志，无符号减法发生借位时置 1；
- \(PF\)：奇偶标志，结果低 8 位中 1 的个数为偶数时置 1。

有些架构中记作 \(Z, N, V, C\)，分别对应 \(ZF, SF, OF, CF\)。

### 1. 基于单个标志位的跳转

| 跳转类型 | 含义 | 逻辑表达式 | 常见指令 |
|---|---|---|---|
| 为零跳转 | 结果 = 0 | \(ZF = 1\) | JE / JZ |
| 非零跳转 | 结果 ≠ 0 | \(ZF = 0\) | JNE / JNZ |
| 符号为负 | 结果为负 | \(SF = 1\) | JS |
| 符号非负 | 结果非负 | \(SF = 0\) | JNS |
| 溢出 | 有符号溢出 | \(OF = 1\) | JO |
| 无溢出 | 有符号无溢出 | \(OF = 0\) | JNO |
| 进位/借位 | 无符号借位 | \(CF = 1\) | JC / JB |
| 无进位/借位 | 无符号无借位 | \(CF = 0\) | JNC / JAE |
| 偶校验 | 低 8 位 1 的个数为偶 | \(PF = 1\) | JP / JPE |
| 奇校验 | 低 8 位 1 的个数为奇 | \(PF = 0\) | JNP / JPO |

用于比较 \(A\) 和 \(B\) 作为**无符号数**：

| 条件          | 含义   | 逻辑表达式                   | 常见指令            |
| ----------- | ---- | ----------------------- | --------------- |
| \(A = B\)   | 相等   | \(ZF = 1\)              | JE / JZ         |
| \(A \ne B\) | 不等   | \(ZF = 0\)              | JNE / JNZ       |
| \(A > B\)   | 大于   | \(CF = 0\) 且 \(ZF = 0\) | JA / JNBE       |
| \(A \ge B\) | 大于等于 | \(CF = 0\)              | JAE / JNB / JNC |
| \(A < B\)   | 小于   | \(CF = 1\)              | JB / JNAE / JC  |
| \(A \le B\) | 小于等于 | \(CF = 1\) 或 \(ZF = 1\) | JBE / JNA       |

记忆：**无符号比较主要看 \(CF\)**。

---

### 3. 有符号数比较跳转

用于比较 \(A\) 和 \(B\) 作为**有符号数**：

| 条件          | 含义   | 逻辑表达式                      | 常见指令            |
| ----------- | ---- | -------------------------- | --------------- |
| \(A = B\)   | 相等   | \(ZF = 1\)                 | JE / JZ         |
| \(A \ne B\) | 不等   | \(ZF = 0\)                 | JNE / JNZ       |
| \(A > B\)   | 大于   | \(ZF = 0\) 且 \(SF = OF\)   | JG / JNLE / BGT |
| \(A \ge B\) | 大于等于 | \(SF = OF\)                | JGE / JNL / BGE |
| \(A < B\)   | 小于   | \(SF \ne OF\)              | JL / JNGE / BLT |
| \(A \le B\) | 小于等于 | \(ZF = 1\) 或 \(SF \ne OF\) | JLE / JNG / BLE |

记忆：**有符号比较看 \(SF\) 与 \(OF\) 是否相等**，同时结合 \(ZF\) 排除相等。

---

### 4. 与 0 比较的特殊情况

当 \(B = 0\) 时，执行 \(A - 0 = A\)，此时**不会发生有符号溢出**，所以 \(OF = 0\)。

| 条件          | 含义    | 逻辑表达式                   | 说明                                   |
| ----------- | ----- | ----------------------- | ------------------------------------ |
| \(A > 0\)   | 有符号正数 | \(ZF = 0\) 且 \(SF = 0\) | 因为 \(OF=0\)，\(SF = OF\) 简化为 \(SF=0\) |
| \(A \ge 0\) | 有符号非负 | \(SF = 0\)              |                                      |
| \(A < 0\)   | 有符号负数 | \(SF = 1\)              |                                      |
| \(A \le 0\) | 有符号非正 | \(ZF = 1\) 或 \(SF = 1\) |                                      |
| \(A = 0\)   | 零     | \(ZF = 1\)              |                                      |
| \(A \ne 0\) | 非零    | \(ZF = 0\)              | 对无符号也适用                              |

---

### 5. 特殊寄存器为零跳转

| 指令    | 条件      | 逻辑表达式       |
| ----- | ------- | ----------- |
| JCXZ  | CX = 0  | \(CX = 0\)  |
| JECXZ | ECX = 0 | \(ECX = 0\) |
| JRCXZ | RCX = 0 | \(RCX = 0\) |

这些不依赖标志位，直接判断寄存器内容是否为零。

---

### 6. 总结表

| 跳转含义 | 标志位逻辑表达式 |
|---|---|
| 等于 | \(ZF = 1\) |
| 不等于 | \(ZF = 0\) |
| 无符号大于 | \(CF = 0\) 且 \(ZF = 0\) |
| 无符号大于等于 | \(CF = 0\) |
| 无符号小于 | \(CF = 1\) |
| 无符号小于等于 | \(CF = 1\) 或 \(ZF = 1\) |
| 有符号大于 | \(ZF = 0\) 且 \(SF = OF\) |
| 有符号大于等于 | \(SF = OF\) |
| 有符号小于 | \(SF \ne OF\) |
| 有符号小于等于 | \(ZF = 1\) 或 \(SF \ne OF\) |
| 有符号大于 0 | \(ZF = 0\) 且 \(SF = 0\) |
| 有符号小于 0 | \(SF = 1\) |
| 溢出 | \(OF = 1\) |
| 无溢出 | \(OF = 0\) |
| 符号为负 | \(SF = 1\) |
| 符号非负 | \(SF = 0\) |
| 进位/借位 | \(CF = 1\) |
| 无进位/借位 | \(CF = 0\) |

核心口诀：

- **等于看 \(ZF\)**；
- **无符号看 \(CF\)**；
- **有符号看 \(SF\) 和 \(OF\) 的关系**；
- **与 0 比较时有符号溢出 \(OF=0\)，条件可简化**。



==区分正溢和负溢==
- 向正方向溢出为正溢，向负方向溢出为负溢

EBX,ESI,EDI是被调用者保存，被调用者结束之后要恢复原样


在p调用q的过程中
实现整个调用过程的关键指令是call 和 ret

下面举例子
p:
	call q（在执行这条指令的时候将下一条指令的地址存放到栈里）
	mov [ebp-4],eax
	mov eax,[ebp-4]
	上面代码的意思是 执行完q的过程调用，然后从eax（存放上一个过程的返回值）中取出来上一个过程的返回值并放到[ebp-4]的位置。

q:
	执行代码逻辑
	ret (当执行到这条指令的时候会跳转回 mov [ebp-4],eax 来执行)
	（具体来说就是将栈里的地址弹出来放到PC中）

当执行到call指令的时候，pc自动指向call指令的下一条地址，也就是返回地址
**作用一**call指令将pc(这里将其称为旧值)压入栈中，**作用二**将pc的值改为调用的函数的第一条指令的地址


x86中栈底(ebp)在高地址，栈顶(esp)在低地址
ebp减去某个长度得到esp , 这是栈帧的长度

指令Push ，Pop是基于esp 也就是栈顶进行的操作
压栈的话先将esp-4（指向下一个单元）然后把数据填进去
弹栈的话，将数据弹出到指定的位置，然后esp+4（指向上一个单元）

## 第五章 CPU


**多处理器基本概念**
- 多处理机：有多个CPU核心（每个核心都拥有自己的一套**控制部件、运算部件、寄存器和局部缓存**），既可以有独立的Cache又可以共享一个Cache ; 共享内存；会出现资源争抢的现象。

- 阵列处理机：类似向量处理机 属于SIMD，又叫并行处理机

- 超线程：==一个物理CPU==模拟两个逻辑CPU，需要操作系统支持，需要硬件支持；（构建于乱序执行和多发射的架构下）
	- 核心目的是当一个线程因为缓存未命中，分支失误，数据相关出现气泡的时候让另一个线程使用这些本来会闲着的资源。
	- 在同一周期可能一部分端口执行线程A的整数运算；另一部分执行线程B的浮点运算；
	- 会出现相互干扰！当两个线程同时需要某个资源的时候，其中一个线程挂起；
- 概念辨析：
	- 时间并行：流水线是时间上的并行
	- 空间并行：多CPU是空间上的并行
- SMP 对称多处理
	- 每个CPU的核心都是平等的，共享相同的物理内存，IO设备
	- 无主从之分
- 硬件多线程中的==SMT(同时多线程)==就是超线程
- 超线程----将线程信息用硬件保留，切换快----==单处理器==

- 共享内存多处理器的基本概念
	- 具有==共享单一物理地址空间==的多处理器系统称为 共享内存多处理器（SMP）
	- 所有CPU均可以通过常规的访存指令访问内存中的任意位置
	- 根据延迟特性划分为两类----UMA(同一存储访问，访问任意内存单元的延迟基本相同)----NUMA(非同一存储访问，延迟取决于CPU与目标内存的物理位置关系)
	- 早期北桥结构--UMA---总线争抢严重

- 多核CPU，不是多个CPU，是一个CPU上集成多个执行内核

## 第七章 IO

总结 通道与DMA方式：

- **DMA：** 是一种**硬件控制器**（DMAC）。它本身没有指令系统，不能执行程序。它只是一组寄存器和控制逻辑的集合，只能按照CPU预先设置好的参数（如源地址、目的地址、传输长度）进行单调的数据搬运。


- **通道：** 是一种**特殊的、通道专用的处理器（I/O处理器）**。它拥有自己的**指令系统**（通道指令），可以执行存储在主存中的**通道程序**。它不仅能传输数据，还能进行简单的逻辑判断、控制设备启动/停止以及处理异常。

- 在通道模式下CPU只需编制一个通道程序，并把通道程序的首地址交给通道，CPU发送启动通道的指令后，通道就完全独立地执行通道程序，直到整套复杂的IO任务全部完成，通道才向CPU发出一次终端
- 通道可以控制多个设备同时或交替工作，能够直接控制外设物理动作


通道的结构复杂，分类如下：
- 字节多路通道，适用于大量低速设备，如键盘，打印机，以字节为单位轮流为各个设备服务
- 选择通道，用于高速设备（磁盘），一段时间内只为一个设备独占服务，以块为单位传输
- 数组多路通道，既能支持高速设备又能实现多设备交叉并行工作



关中断，保存断点，保存程序状态字，==找到==中断服务==入口==。

设备两种类型，
- 一种设备按照自己的接口向缓冲区里放数据，如果CPU不及时拿走导致数据丢失
- 另一种设备会根据CPU的指挥，向IO缓冲区里冲入数据，cpu取出之后会指挥IO设备输入下一个字的数据，不会有数据丢失问题
